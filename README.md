# timed-math-challenge
A Python-based timed math challenge that generates random arithmetic problems and tracks how long you take to solve 10 questions.

# Timed Math Challenge

A simple Python game that tests your math skills by generating random arithmetic problems and measuring the time taken to solve them.

## Features
- Generates random math problems.
- Supports addition, subtraction, and multiplication.
- Provides 10 problems per round.
- Checks answers and allows retries for incorrect answers.
- Tracks the total time taken to complete the challenge.

## Requirements
- Python 3

## How to Run

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the following command:

```bash
python3 timed_math_challenge.py
```

## How to Play

1. Run the program.
2. Press Enter to start the challenge.
3. Solve each math problem by entering your answer.
4. If your answer is incorrect, try again until you get it right.
5. Complete all 10 problems to see your total completion time.

## Technologies Used
- Python
- `random` module
- `time` module
- Functions, loops, and conditional statements
